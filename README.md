# CodeShield——多语言代码敏感信息扫描与泄露风险评估工具

## 1. 项目简介

CodeShield 是一套本地运行的多语言代码敏感信息扫描与泄露风险评估工具，用于发现软件项目中密码、API Key、Token、Private Key、数据库连接凭证及个人敏感信息等潜在泄露风险。

系统全程本地离线分析，不上传用户源码；对敏感内容默认脱敏，原始 Secret 不写入扫描历史、报告和日志。

## 2. 功能说明

- 本地代码项目目录扫描；
- 支持 Python、Java、JavaScript/TypeScript、C/C++、R、Rust 及常见配置文件；
- 检测 Password、API Key、Secret、Token、JWT、Private Key、数据库凭证、邮箱、手机号、身份证号等敏感信息；
- 正则规则匹配；
- 敏感变量与硬编码上下文分析；
- Shannon 信息熵检测；
- 0～100 可解释风险评分；
- 严重、高、中、低四级风险分级；
- 敏感信息默认脱敏；
- 扫描结果搜索与多维筛选；
- SQLite 扫描历史保存与回看；
- 风险处理状态（未处理、已确认、误报、已忽略、已修复）；
- 指纹、文件、目录、规则四类白名单；
- 内置规则启用 / 禁用；
- 自定义检测规则；
- 同一项目扫描前后风险对比；
- 离线 HTML 报告与 JSON 报告导出；
- 后台线程扫描、实时进度与协作式取消；
- 全程本地离线处理。

## 3. 支持的编程语言与文件类型

| 类型 | 后缀 / 文件名 |
| --- | --- |
| Python | `.py` |
| Java | `.java` |
| JavaScript | `.js`、`.jsx` |
| TypeScript | `.ts`、`.tsx` |
| C | `.c`、`.h` |
| C++ | `.cpp`、`.hpp` |
| R | `.r` |
| Rust | `.rs` |
| 配置文件 | `.env`、`.ini`、`.conf`、`.cfg`、`.properties`、`.yaml`、`.yml`、`.json`、`.xml`、`.toml` |

扫描会递归遍历所选目录，自动忽略 `.git`、`node_modules`、`build`、`venv` 等常见目录，跳过符号链接、二进制文件与超过大小上限的文件。

## 4. 支持检测的敏感信息类型

- 硬编码密码（Password）
- API Key
- Secret
- Token
- JWT Token
- Private Key（私钥文件头）
- 带认证信息的数据库连接串（URI / JDBC）
- 邮箱（Email）
- 手机号（Phone）
- 身份证号（ID Card）

其中邮箱、手机号、身份证号属于个人信息检测，可在扫描配置中关闭。

## 5. 核心检测原理

```
规则匹配
+ 上下文关键词分析
+ Shannon 信息熵
+ 结构验证
+ 误报降权
↓
可解释风险评分
```

- 先由正则规则在源码行中定位候选凭证，只对命中规则的候选进行后续分析；
- 上下文分析识别敏感变量名、直接字符串赋值、注释、测试或演示路径、占位值；
- Shannon 信息熵与字符串长度作为凭证可信度因子；**高信息熵只是风险因子之一，不会单独作为严重风险判定依据**；
- 身份证校验位、JWT 三段式结构与数据库凭证来源做结构验证；
- 环境变量读取、动态配置读取、测试目录、注释、占位值等因素参与误报控制，降低评分而不直接删除结果。

## 6. 风险评分与风险等级

- 0～29：低
- 30～49：中
- 50～74：高
- 75～100：严重

| 等级 | 颜色 |
| --- | --- |
| 严重 | 红色 |
| 高 | 橙色 |
| 中 | 黄色 |
| 低 | 蓝色 |

每条风险会列出评分因子明细（规则命中、敏感变量、直接赋值、信息熵、格式证据、注释 / 测试路径 / 占位值 / 动态来源降权等），评分依据可解释。

## 8. 环境配置

- 操作系统：Windows 10 / Windows 11
- Python：3.11（项目实际验证版本）

## 9. 安装依赖

在项目根目录执行：

```powershell
python -m venv .venv
```

Windows CMD：

```cmd
.venv\Scripts\activate
```

安装依赖：

```cmd
python -m pip install -r requirements.txt
```

## 10. 运行步骤

启动配置与数据库自检：

```cmd
python main.py --check
```

启动桌面程序：

```cmd
python main.py
```

使用流程：

1. 启动 CodeShield；
2. 点击左侧“项目扫描”；
3. 点击“选择项目”并选择本地源码目录；
4. 根据需要调整扫描配置（文件大小上限、是否检测个人信息）；
5. 点击“开始扫描”；
6. 等待扫描完成；
7. 进入“扫描结果”查看风险；
8. 点击具体风险查看检测依据、评分和修复建议；
9. 可通过“扫描历史”查看历史记录；
10. 可通过“白名单”管理误报；
11. 可通过“检测规则”管理规则；
12. 可通过扫描对比查看风险变化；
13. 可在“报告中心”导出 HTML 或 JSON 报告。

命令行模式：

```cmd
python main.py --scan-demo
```

```cmd
python main.py --scan-demo --explain
```

```cmd
python main.py --scan C:\Projects\example
```

命令行只显示相对路径、位置和脱敏值，不输出匹配到的完整凭证。

## 11. 软件使用说明

- **概览**：展示累计扫描项目、文件、风险与严重风险统计，以及累计风险等级分布和最近完成扫描列表；
- **项目扫描**：选择目录、调整扫描配置、开始或取消扫描，实时显示进度与当前文件；
- **扫描结果**：按关键词、等级、类型、语言筛选风险项，查看脱敏内容、检测依据、评分因子、脱敏上下文与修复建议，可修改处置状态或加入白名单；
- **扫描历史**：回看历史扫描快照，支持搜索、状态筛选、详情打开与删除，并可发起扫描对比；
- **检测规则**：启用 / 禁用内置规则，新增、编辑、删除自定义规则；
- **白名单**：按风险指纹、文件路径、目录前缀、规则四类管理，被白名单命中的结果在扫描中被抑制；
- **报告中心**：选择已完成扫描，导出离线 HTML 或 JSON 报告；
- **设置**：查看当前生效的本地扫描默认值。

## 13. 数据安全与隐私说明

设置与扫描历史存放在当前 Windows 用户的 `%LOCALAPPDATA%\CodeShield`，受限环境无法写入时回退到项目内的 `.codeshield_data`。

数据库只保存脱敏值、脱敏上下文、风险因子和 SHA-256 指纹，不保存完整密码、Token、私钥等原始 Secret。扫描对比与报告导出只读取 SQLite 中的脱敏快照，不会为展示或导出重新读取源码。历史中的本地项目路径不会上传或发送到任何外部服务。
